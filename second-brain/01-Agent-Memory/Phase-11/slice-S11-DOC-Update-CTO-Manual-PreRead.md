## What Changed

Locked the MANDATORY PRE-READ block into `AGENTS-CTO.md` Section 7 ("Kilo Slice Prompt Structure") template. Every future Kilo slice prompt generated by the Cloud CTO will now include the pre-read requirement at the top, right after `SLICE: [Name]`:

```
MANDATORY PRE-READ:
1. Read `AGENTS.md` completely.
2. Read `second-brain/00-Current-State.md` completely.
Do not write a single line of code until these are loaded into your context.
```

This prevents Kilo from skipping context loading and producing out-of-context code changes.
