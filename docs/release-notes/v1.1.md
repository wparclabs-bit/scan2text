# Scan2Text v1.1

**First public release.**

## What it is

Scan2Text is an offline, CPU-only, portable OCR application that converts images and PDFs into Markdown files. No internet connection required after download.

## Supported inputs

- PNG
- JPG / JPEG
- WEBP
- PDF

## Limits

- Maximum 10 files per batch
- Maximum 20 MB per file

## Output

Markdown (`.md`) files, written to the `output/` directory.

## What's included

The Full ZIP contains the complete application plus all required model files — ready to run immediately after extraction.

## Known limitations

- Horizontal table scrollbar is accepted as-is; tables wider than the preview panel scroll horizontally within the preview area.
- Multi-instance portable mode is not supported; running a second instance will attach to the first.
- Single-instance plugin is currently parked and inactive.
