# How to Update Scan2Text

## Automatic Model Updates

Models update automatically inside the app. When a new model is available, Scan2Text will download it for you — no action needed on your part. The app verifies each model using a security hash before installing it.

## Manual App Updates

When a new version of Scan2Text is released, follow these steps:

1. **Download the latest zip** from the release page.
2. **Close Scan2Text** completely before extracting.
3. **Extract the zip** to a temporary folder.
4. **Replace the files** — copy everything from the extracted folder into your existing Scan2Text installation folder, overwriting old files.
5. **Keep your data safe** — never delete the `settings`, `output`, or `logs` folders during an update. These contain your preferences and processed documents.
6. **Restart Scan2Text**.

> **Warning:** Never delete the `settings` or `output` folders during an update. You will lose your preferences and processed files.
